# 原生 TMDb 验收（v0.7.11）

macOS DMG 与 Android APK 使用 Rust 网络请求和设备本地 SQLite，刮削不需要 Go 服务。安装包版本和应用页脚应显示 0.7.11。以下为手动检查步骤，未记为已经完成实机验收。

1. 使用原发布密钥签名的 APK 覆盖升级，或将新 macOS App 替换到 Applications；保留应用数据，确认旧收藏、评分、短评和海报仍在。
2. 点击添加按钮进入 TMDb 搜索。填写个人 API Key／读取令牌；原生端不提供 Go 服务端默认 Key。网络需要代理时，可在 API 设置填写 API 与图片基础地址。
3. 搜索电影，检查片名、简介、海报候选和预告片。选择字段及海报、背景、Logo，应用后填写个人记录并确认保存。
4. 搜索剧集／番剧，分别选择整剧、单季和特别篇；检查季度名、集数、单集列表及关联人物图片。
5. 关闭 App 后断网重开，确认保存的详情、头像、单集图片和海报可读取。
6. 从详情页更新 TMDb，只选一个资料字段，确认个人评分、短评、观看年月、观看状态、播放链接和未选择字段保持不变。
7. 再次导入同一电影或同一季，确认提示已有收藏并能打开原记录。不同季可分别收藏。
8. 手动编辑作品资料和图片，再次打开核对；播放链接、TMDb 来源和预告片应交给系统默认应用打开。
9. 故意设置错误的图片代理后导入，确认错误可重试，未创建不完整收藏。返回或取消后不应误保存记录。

个人 Key 只保存在当前会话及预览内存，不进入数据库或导出文件。原生数据库启动迁移增加 metadata 与 local_revision，不重建旧收藏表。原生与 Go 服务之间的自动同步尚未实现。

自动验证：在项目根目录运行 `cargo test --locked --manifest-path src-tauri/Cargo.toml --lib`。测试使用本地 HTTP fixture 和临时 SQLite，覆盖迁移、电影／季度资料、字段选择、图片去重及预下载复用、失败清理、取消、重复记录、资料编辑并发检查、个人记录保护与重启后离线读取。
