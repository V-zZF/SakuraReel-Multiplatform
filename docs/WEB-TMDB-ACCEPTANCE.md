# Web 端 TMDb 功能验收

本轮覆盖 React、Go HTTP 服务和服务端 SQLite。主页与排行榜沿用现有布局和排序，仅接入搜索／详情入口及保存后的数据刷新。时光机没有修改。Tauri／Rust 和多平台封装留待 Web 验收后讨论。

## 本地存储

作品文字资料保存在运行 Go 服务的电脑上的 `anime.db`，选中的海报、背景图和 Logo 保存在数据库旁的 `posters/`。详情页读取这些本地资料，不会自动请求 TMDb。搜索、预览和主动更新才访问 TMDb；浏览器是操作界面，数据库不存放在浏览器内。

作品资料包含 TMDb 来源、简介、上映／首播日期、制作公司、演职员、季度／单集摘要及参考时长。个人评分、短评、观看年月、收藏状态、播放链接和排序独立保留。备份时同时备份 `anime.db` 与整个 `posters/` 目录。

## 启动与操作

```sh
cd ui
npm ci
npm run build
cd ../server
go run . -data ../dist/web-acceptance/data -port 2333
```

使用前创建独立的数据目录，浏览器打开 `http://localhost:2333`。该目录用于验收，不连接或修改日常收藏库。

1. 点击主页右下角「＋」。未选择连接方式时显示「TMDb 使用指引」；注册、登录、申请 API 为独立链接。填写个人 API Key／读取令牌后点击「保存并搜索」。
2. 搜索页右上角齿轮打开独立 API 设置页，代理地址仅用于个人 Key；地球按钮切换资料语言。返回保留关键词、分类、页码和滚动位置。
3. 有服务端默认凭据时，指引页显示「跳过，使用默认 API（不稳定）」。默认 API 不使用浏览器填写的代理，也不把服务端 Key 下发给浏览器。服务端未配置时隐藏入口。
4. 搜索结果为单列卡片，点击作品进入下一步；番剧＝日本动画 TV，节目＝其他 TV，电影＝全部电影。TV 在「按季选择」页选择整剧、普通季或特别篇。选定电影或收藏范围后，先获取资料并显示导入预览，确认所选字段后，在准备图片时打开原手动添加表单填写个人记录。
5. 预览先显示海报候选。背景图和 Logo 独立折叠，可展开选择；每类图片均可单独重新获取。资料按基本信息、演职员、季度／单集、扩展档案分组，使用粉色开关选择，长列表展开查看。
6. 新收藏表单默认「想看」，预览不再显示观看状态控件，可通过「编辑添加信息」返回表单；更新默认补空字段。已有资料的当前值在字段行展开查看，非空资料需要主动选择覆盖。部分失败的资料默认不选中，扩展档案支持只重试失败组。
7. 点击底部「应用所选字段」，下载所选图片并一次保存本地资料、改写片名与新收藏的个人记录，完成后进入详情。整剧、普通季、特别篇分别收藏；重复来源提示打开已有收藏。
8. 详情优先展示背景／Logo、日期／集数／作品状态／类型，以及我的评分、观看年月、总时长和短评。下面独立卡片显示简介、资料、演职员、季集、预告片与扩展档案。
9. 圆形按钮依次为 TMDb 来源、分享、更多。更多菜单进入资料编辑、个人记录编辑、TMDb 更新或播放链接；编辑与更新切换当前页面。分享仅发送作品名称和公开 TMDb 来源链接。
10. 返回上一步保留导入选择；初始默认选择不会触发未保存确认。实际修改后退出、按 Escape 或浏览器返回会提示保存、放弃、继续编辑。刷新／关闭标签页使用浏览器未保存提示。

### 服务端默认 API 配置

启动服务前可配置 `TMDB_READ_TOKEN` 或 `TMDB_API_KEY`，令牌优先。可选 `TMDB_API_BASE`（默认官方 API `/3` 地址）和 `TMDB_IMAGE_BASE`（默认官方图片 `/t/p` 地址）也由服务端控制。配置通过进程环境提供，不写进收藏库或前端资源；修改后需重启服务。`GET /api/tmdb/config` 只返回 `default_available` 布尔值。

个人 Key 无效时直接报错，不自动改用默认凭据。Key 无需发到聊天中。没有真实默认凭据时，仍可完整使用个人 Key 和手动添加。

### 完整作品档案

本轮新增类型、季度名、作品状态、标语、语言／国家、最后播出日期、季数、TMDb 评分／票数、电影预算／票房／系列、电视网、创作者、官方网站，以及别名、翻译、关键词、分级／发行、外部 ID 和预告片。季收藏明确区分整剧状态与季度日期／简介／集数。

单集包含日期、时长、摘要，并保留来源提供的评分、制作编号、客串演员、制作人员和剧照。演职员头像及单集关联图片随所选资料组下载到本地；不选中的组保持原值。来源 ID 为只读，文字与列表用表单编辑，不显示 JSON。

预告片保存元数据及 YouTube／Vimeo 播放链接，不下载视频；不接入观看平台、推荐／相似作品、公开评论、人物百科或 TMDb 账号操作。旧 metadata JSON 向前兼容，不重建数据库。

## 当前行为与限制

- Key 仅在当前浏览器会话保留，不写入收藏库或日志；语言和代理偏好保存在浏览器本地。关闭浏览器会话后可能需要重新填写 Key。
- 预览有效期为 30 分钟，服务重启后需要重新获取预览。确认前不会创建收藏。
- TV 分类基于 TMDb 提供的动画类型和来源国家。文本搜索使用 TMDb 原始分页后按分类过滤，部分页可能结果较少或为空，仍可翻页。
- 翻译缺失时尽量补充原语言资料；TMDb 本身未提供的日期、摘要、图片或时长会显示未知／未提供。
- 剧集总时长是集数乘以参考单集时长，标注「约」和依据。整剧总时长不计特别篇，特别篇单独收藏时按该季计算。
- 图片保存失败时不会提交收藏，可重试或取消失败图片。季度请求部分失败会显示提示，单集摘要默认不选中，避免将不完整列表覆盖本地资料。
- 保持已有服务端同步数据接口兼容；本轮不新增自动跨端同步或原生端图片适配。

## 交互修订（2026-10-03）

当前顺序为搜索／选范围 → 导入预览 → 点击「应用所选字段」 → 个人记录表单 → 保存并收藏。选中图片和对应演职员／单集图片在填写期间通过 prepare_only 请求准备，顶部小提示显示实际进度；准备阶段不写收藏。最终保存复用已准备的图片并一次提交资料与个人记录。取消返回预览，失败显示恢复入口；已有收藏更新不打开新收藏表单。

搜索和预览固定内容视口高度，加载时不缩小。搜索底部手动添加只有悬浮按钮，没有白底或模糊横条。详情去掉标题栏，背景图直接位于顶部，关闭按钮固定在右上角；官网、分享、播放、更多均位于背景图区域底部。评分、观看年月、短评卡片可点击或用键盘打开个人编辑，定位对应字段。

扩展档案已从详情、预览和资料编辑分组移除；不再请求别名、翻译、关键词、分级／发行、外部 ID。预告片保留独立请求和展示。旧收藏已有扩展字段兼容保留，不清除。

手机详情的评分、观看年月、总时长采用等宽正方形卡片，减少图标、数值和标签的纵向间隙；观看年月可两行显示。验收检查正方形比例及内容不溢出。

本次构建、浏览器回归、Go race 测试与 vet 通过；320／390／430px 三种手机宽度的正方形记录卡片及内容边界已检查。2333 验收服务已重建重启，沿用原有数据目录。lint 仅有原有 RatingCircle 热更新警告。

## 详情入场与默认 API（2026-10-03）

详情首次打开启用从点击卡片位置展开的缩放、位移与淡入动画；减少动态效果设置继续生效。浏览器测试检查实际动画帧及最终缩放。
