# server/frontend/dist — 临时占位（阶段 B → 阶段 D）

`dist/` 里的东西是从 `MAL/frontend/dist` **原样拷贝**过来的已构建前端产物（拷贝于 2026-09-22）。

- 服务端用 `//go:embed frontend/dist` 把它打进单文件二进制，浏览器打开 `http://localhost:2233`
  看到的就是这份界面。
- 阶段 B 的目标是「后端搬进来先原样能跑、旧页面照旧可用」，所以先把产物放这里。
- **阶段 D** 会把 `MAL/frontend` 的源码搬进 `ui/`、重新 `npm run build` 到 `ui/dist`，
  同时把 `main.go` 的 embed 路径改成 `ui/dist`；到那时这份拷贝删掉。

不要直接改这里的文件（这是构建产物，改了下一次拷贝/构建就没了）。
要改界面：等阶段 D 之后改 `ui/` 源码重新构建。

  阶段 D 从 `ui/` 源码重新构建时，版本号要按同一套规则正式写进源码。
